# 丹炉桌面客户端（desktop/src）

范围：主窗口（总览、历史、服务器、设置，右侧分栏的任务详情和提交表单）和托盘旁的迷你总览（tray.html）。模式：Operate。

用户要做的事：一屏看清所有服务器的空卡和任务；没看过的失败排在最前；在右侧分栏读实时日志、代码快照，取消、重跑、复制任务；提交到任意一台；在服务器页做升级和服务管理。常驻托盘，失败和异常时被通知叫回来。

约束：和面板（web/）的视觉完全独立；平台无关，以后 macOS 上看起来一样；纯色窗口，不用云母、亚克力、半透明；字体随安装包打包；信息密度不能降；键盘优先，取消任务必须点按钮确认。

## Direction contract

THESIS: 一个克制的现代开发者工具，做工参照 Linear、Raycast，但更收敛。中性灰阶的层次台阶承载结构，颜色只说状态。拒绝"大圆角卡片 + 彩色主按钮 + 图标瓷砖"的仪表盘模板，也拒绝跟随某一个操作系统的原生外观。

OWN-WORLD: 四层底色台阶：窗口底（深 #0a0b0d / 浅 #e8eaee）→ 内容面板（#121317 / #fff，10px 圆角，细边加很淡的投影）→ 详情卡片（#18191e / #f6f7f9，只靠底色和细边）→ 日志终端（两种主题都是深色）。细边是白 6% / 黑 7%。主按钮是反色的墨（深色白底黑字），选中项是底色加一圈内描边，不用彩色。状态色：运行蓝、成功绿、失败红、外部占卡琥珀；排队和取消用弱文字色。朱砂只在火焰标志。Geist 和 Geist Mono 打包；编号、数字、命令、路径、日志用等宽。控件 6px 圆角，日志 8px，托盘浮窗 12px（系统窗口圆角）。

STORY: 打开就能读出：哪里有没看过的失败、哪些在跑跑到哪了、哪台有空卡。点一行，右侧淡入详情，日志在跑；按 C 复制到表单，换一台、改两个字段、Ctrl+Enter 提交。平时只看托盘图标：灰是空闲，朱砂是炉火在烧，红点是该回来看了。

FIRST VIEWPORT: 自绘标题栏 38px：左火焰标志和"丹炉"，中间筛选框（Ctrl K），右边窗口按钮。左侧 40px 窄导航（总览、历史、服务器，设置在底部）。主体是一块内容面板：顶部空卡条，每台服务器一行热力色块（卡号、占用者、利用率、5 分钟小曲线、显存），离线的整排变淡写"5m 前"；下面是筛选（服务器、项目、状态）和右侧的"新建任务 N"主按钮；再下面是 30px 一行的任务列表，没看过的失败在最前、行尾红点。选中任务时右侧出现约 540px 的详情面板。

FORM: 用户在 docs/CLIENT.md 第 5.4 节（v0.5–v0.6，两轮选择后"层次再收一点"）钉死了方向，按 new-work 的规定，用户钉死的方向优先于抽签，因此没有运行 concept-seed，也没有种子键。构建方式：code-led（本机没有图像生成）。签名交互：任务状态变化时整行用新状态色闪一下（1.2s 淡出）；托盘浮窗从托盘方向淡入并从 98% 放大。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
